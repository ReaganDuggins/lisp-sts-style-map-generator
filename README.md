# lisp-sts-style-map-generator
A simple generator that makes and formats a string to form a list of room types starting with an entrance and ending with a boss, with three paths, in the style of Slay the Spire and other similar games.

You can watch me make this project in one day here: (link coming as soon as the video is on YouTube)


# How To Run It
I used the Common Lisp variant called Steel Bank Common Lisp. You'll need to install that first.

With that installed, you can simply run: `sbcl --script filename.lisp` to run it.
